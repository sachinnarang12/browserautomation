Installation Steps

1

Install Python

Download Python 3.11 from python.org/downloads

Important: Check "Add Python to PATH" during installation.
2

Extract AutomatePortal

Extract the delivered ZIP file to your preferred location, e.g.:

C:\AutomatePortal\
3

Run the Installer

Open the extracted folder and double-click install.bat

This will:

  • Create an isolated Python virtual environment
  • Install all required dependencies
  • Initialize the database
  • Create application directories
  • Generate launcher shortcuts
4

Launch AutomatePortal

Double-click Start AutomatePortal.bat

Your browser will automatically open to the setup wizard.

5

Complete Setup Wizard

  1. Set Admin Password — Replace the default password (min 8 characters)
  2. Enter API Key — Your Nova Act API key (provided separately)
  3. Configure Preferences — Company name, download directory, admin email
6

Activate License

After logging in, go to Settings → License and enter your license key.

Format: AP-PRO-20270309-A3F2-8B4C1D2E
Done! AutomatePortal is now ready. Create your first automation task from the Tasks page.

Daily Usage

Starting the Application

Double-click Start AutomatePortal.bat each time you want to use it.

Stopping the Application

Press Ctrl+C in the terminal window, or simply close the terminal.

Accessing the Dashboard

Open your browser to: http://localhost:5000

Troubleshooting
